📥 Importar módulo HTML

Pega aquí el módulo HTML (generado por la IA con el prompt maestro) con data-module-type igual a topic, pathogen, concept o flashcard. El data-topic de cada patógeno/concepto debe escribirse EXACTAMENTE igual al data-name del módulo topic correspondiente: así quedan agrupados en "Temas". Los patógenos también pueden incluir data-mechanism (mecanismo/acción) y data-treatment (tratamiento o prevención) para agruparlos en "Patógenos". Nada se duplica: se actualiza por data-id o data-name.

💾 Copia de seguridad (recomendado para usar en varios dispositivos)

Descarga tu biblioteca como archivo .json y guárdala en la nube (Drive, correo, etc.). En cualquier otro dispositivo, abre esta misma página e importa el archivo para tener todo tu contenido al instante. Este método funciona siempre, sin importar dónde abras el archivo.

Herramientas

Gestionar biblioteca

Acá podés revisar todo lo que se cargó (temas, patógenos, conceptos y flashcards) y borrar lo que se haya agregado mal, esté repetido o ya no quieras tener. Los cambios se guardan automáticamente y se reflejan en toda la app.
